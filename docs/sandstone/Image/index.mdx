# sandstone/Image

Provides Sandstone styled Image component that supports multiple resolution sources.


## Exports

This module exports the following:

- `Image`
- `ImageBase`
- `ImageDecorator`


## Examples

<LiveExample code={`<Image src="https://dummyimage.com/64/e048e0/0011ff" style={{height: 64, width: 64}} />`} runner="sandstone" title="Try it" />


## API Reference


### Classes

#### ImageBase

<span className="badge badge--secondary">class</span> 

A Sandstone-styled image component without any behavior


---


#### Instance Members

##### componentRef

Called with a reference to the root component.

When using [sandstone/Image.Image](#sandstone-image.image), the `ref` prop is forwarded to this component
as `componentRef`.


---

##### css

Customizes the component by mapping the supplied collection of CSS class names to the
corresponding internal elements and states of this component.

The following classes are supported:


- `image` - The root component class for Image


---

#### Image

<span className="badge badge--secondary">class</span> 

A Sandstone-styled image component

```
<Image
  src={{
    'hd': 'https://dummyimage.com/64/e048e0/0011ff',
    'fhd': 'https://dummyimage.com/128/e048e0/0011ff',
    'uhd': 'https://dummyimage.com/256/e048e0/0011ff'
  }}
>
```

#### ImageDecorator
