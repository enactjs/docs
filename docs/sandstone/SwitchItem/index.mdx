# sandstone/SwitchItem

Provides Sandstone-themed item component and interactive toggleable switch.


## Exports

This module exports the following:

- `SwitchItem`
- `SwitchItemBase`


## Examples

<LiveExample code={`<SwitchItem>
	Item
</SwitchItem>`} runner="sandstone" title="Try it" />


## API Reference


### Classes

#### SwitchItemBase

<span className="badge badge--secondary">class</span> 

Renders an item with a [Switch](#sandstone-switch).


---


#### Instance Members

##### css

Customizes the component by mapping the supplied collection of CSS class names to the
corresponding internal elements and states of this component.

The following classes are supported:


- `switchItem` - The root class name


---

##### selected

If true the switch will be selected.


---

##### slotAfter

Nodes to be inserted after `children` and before the switch.


---

#### SwitchItemDecorator

<span className="badge badge--secondary">class</span> 

Adds interactive functionality to `SwitchItem`.


---

#### SwitchItem

<span className="badge badge--secondary">class</span> 

A Sandstone-styled item with a switch component.

`SwitchItem` will manage its `selected` state via [Toggleable](#ui-toggleable) unless set
directly.
