# sandstone/Region

This component provides a labeled region to a group of components.


## Exports

This module exports the following:

- `Region`
- `RegionBase`

### Classes

#### Region

#### Instance Members

##### title

Title placed within an instance of [Heading](#sandstone-heading.heading) before the
children.


---

The aria-label for the region.

If unset, it defaults to the value of `title`
