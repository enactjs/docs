# sandstone/RadioItem

Provides a Sandstone-themed Item component with an interactive radio toggle icon.


## Exports

This module exports the following:

- `RadioItem`
- `RadioItemBase`


## Examples

<LiveExample code={`<RadioItem>Item</RadioItem>`} runner="sandstone" title="Try it" />


## API Reference


### Classes

#### RadioItemBase

<span className="badge badge--secondary">class</span> 

An item component with a radio toggle icon.

This component is most often not used directly but may be composed within another component as it
is within [RadioItem](#sandstone-radioitem.radioitem).


---

#### RadioItem

<span className="badge badge--secondary">class</span> 

Renders an `Item` with a radio-dot component. Useful to show a selected state on an Item.


---


#### Instance Members

##### css

Customizes the component by mapping the supplied collection of CSS class names to the
corresponding internal elements and states of this component.

The following classes are supported:


- `radioItem` - The root class name


---

##### icon

The icon to display when selected.


### See Also

- [sandstone/Icon.Icon](#sandstone-icon.icon)




---

##### selected

If true it will be selected.


---

##### slotBefore

Nodes to be inserted after the radio button and before `children`.


---


## Constants

#### RadioItemDecorator

<span className="badge badge--secondary">constant</span> 

Sandstone specific behaviors to apply to [RadioItem](#sandstone-radioitem.radioitembase).
