# sandstone/Switch

Provides a Sandstone-themed pill-shaped toggle switch component.


## Exports

This module exports the following:

- `Switch`
- `SwitchBase`


## Examples

<LiveExample code={`<Switch />`} runner="sandstone" title="Try it" />


## API Reference


### Classes

#### SwitchBase

<span className="badge badge--secondary">class</span> 

Renders the base level DOM structure of the component.


---


#### Instance Members

##### disabled

Disables Switch and becomes non-interactive.


---

##### noAnimation

Disables animation.


---

##### selected

Sets whether this control is in the 'on' or 'off' state. `true` for 'on', `false` for 'off'.


---

#### SwitchDecorator

<span className="badge badge--secondary">class</span> 

Adds interactive functionality to `Switch`.


---

#### Switch

<span className="badge badge--secondary">class</span> 

A Sandstone-styled component that looks like a toggle switch.

`Switch` will manage its `selected` state via [Toggleable](#ui-toggleable) unless set
directly.
