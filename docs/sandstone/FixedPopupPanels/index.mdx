# sandstone/FixedPopupPanels

Provides Sandstone styled fixed-width, popup-styled Panels component.


## Exports

This module exports the following:

- `FixedPopupPanels`
- `FixedPopupPanelsBase`
- `FixedPopupPanelsDecorator`
- `Panel`
- `Header`


## API Reference


### Classes

#### FixedPopupPanelsDecorator

<span className="badge badge--secondary">class</span> 

Adds popup functionality and `rtl` prop to [FixedPopupPanels](#sandstone-fixedpopuppanels).


---

#### FixedPopupPanelsBase

<span className="badge badge--secondary">class</span> 

A base panels component for [FixedPopupPanels](#sandstone-fixedpopuppanels) that has
left key handler to navigate panels.


---

#### FixedPopupPanels

<span className="badge badge--secondary">class</span> 

An instance of [Panels](#sandstone-panels.panels) which restricts the `Panel` to the right
or left side of the screen inside a popup. Typically used for overlaying panels over other
content.


---


#### Instance Members

##### width

Size of the popup.


---


#### Static Members

##### Panel

A shortcut to access [sandstone/FixedPopupPanels.Panel](#sandstone-fixedpopuppanels.panel)


---

##### Header

A shortcut to access [sandstone/FixedPopupPanels.Header](#sandstone-fixedpopuppanels.header)


---

#### Panel

<span className="badge badge--secondary">class</span> 

The standard view container used inside a
[FixedPopupPanels](#sandstone-fixedpopuppanels.fixedpopuppanels) view manager instance.


---

#### Header

<span className="badge badge--secondary">class</span> 

A header component for a Panel with a `title` and `subtitle`, supporting several configurable
[`slots`](#ui-slottable.slottable) for components.
