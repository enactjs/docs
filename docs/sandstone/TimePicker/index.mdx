# sandstone/TimePicker

Provides a Sandstone-themed time selection component.


## Exports

This module exports the following:

- `TimePicker`
- `TimePickerBase`
- `timeToLocaleString`

#### TimePicker

<span className="badge badge--secondary">class</span> 

A component that allows displaying or selecting time.

Set the [value](#sandstone-timepicker.timepicker.value) property to a standard JavaScript
[Date](#-docs-developer-guide-glossary-#date) object to initialize the picker.

By default, `TimePicker` maintains the state of its `value` property. Supply the
`defaultValue` property to control its initial value. If you wish to directly control updates
to the component, supply a value to `value` at creation time and update it in response to
`onChange` events.


---


#### Instance Members

##### defaultValue

Default value


---

##### value

The selected date.
