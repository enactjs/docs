# sandstone/CheckboxItem

Sandstone styled item components with a toggleable checkbox.


## Exports

This module exports the following:

- `CheckboxItem`
- `CheckboxItemBase`
- `CheckboxItemDecorator`


## Examples

<LiveExample code={`<CheckboxItem onToggle={console.log}>
	Item with a Checkbox
</CheckboxItem>`} runner="sandstone" title="Try it" />


## API Reference


### Classes

#### CheckboxItemBase

<span className="badge badge--secondary">class</span> 

A Sandstone-styled item with a checkbox component.

`CheckboxItem` may be used to allow the user to select a single option or used as part of a
[Group](#ui-group) when multiple [selections](#ui-group.group.select) are possible.

Usage:

```
<CheckboxItem
	defaultSelected={selected}
	onToggle={handleToggle}
>
 Item with a Checkbox
</CheckboxItem>
```

#### Instance Members

##### css

Customizes the component by mapping the supplied collection of CSS class names to the
corresponding internal elements and states of this component.

The following classes are supported:


- `checkboxItem` - The root class name


---

##### icon

The icon content.

May be specified as either:


- A string that represents an icon from the [iconList](#sandstone-icon.iconlist),
- An HTML entity string, Unicode reference or hex value (in the form '0x...'),
- A URL specifying path to an icon image, or
- An object representing a resolution independent resource (See [ui/resolution](#ui-resolution))


---

##### indeterminate

Enables the "indeterminate" state.

An indeterminate, mixed, or half-selected state is typically used in a hierarchy or group
to represent that some, not all, children are selected.

NOTE: This does not prevent updating the `selected` state. Applications must control this
property directly.


---

##### indeterminateIcon

The icon to be used in the `indeterminate` state.

May be specified as either:


- A string that represents an icon from the [iconList](#sandstone-icon.iconlist),
- An HTML entity string, Unicode reference or hex value (in the form '0x...'),
- A URL specifying path to an icon image, or
- An object representing a resolution independent resource (See [ui/resolution](#ui-resolution))


---

##### selected

If true the checkbox will be selected.


---

##### slotBefore

Nodes to be inserted after the checkbox and before `children`.


---

#### CheckboxItemDecorator

<span className="badge badge--secondary">class</span>

---

#### CheckboxItem

<span className="badge badge--secondary">class</span> 

A Sandstone-styled item with a checkbox component.

`CheckboxItem` will manage its `selected` state via [Toggleable](#ui-toggleable) unless set
directly.
