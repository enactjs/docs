# i18n/util

A collection of locale-aware text utility function.


## Exports

This module exports the following:

- `isRtlText`
- `toCapitalized`
- `toLowerCase`
- `toUpperCase`
- `toWordCase`


## API Reference


## Functions

### isRtlText

<span className="badge badge--secondary">function</span> 

Takes content `str` and determines whether or not it is [RTL](#-docs-developer-guide-glossary-#rtl).


#### Parameters

<Tabs>
  <TabItem value="str" label="str">
    **Type:** `String`

    A string to check the [RTL](#-docs-developer-guide-glossary-#rtl)-ness of.
  </TabItem>
</Tabs>


#### Returns

**Type:** `Boolean`

`true` if `str` should be RTL; `false` if not.
