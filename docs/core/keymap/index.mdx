# core/keymap

Manages a map of names to key codes to simplify event handlers

Example:

```
import {add, is} from '@enact/core/keymap';

add('enter', 13);
const isEnter = is('enter');

// within event handler
if (isEnter(ev.keyCode)) {
  // handle enter
}
```


## Exports

This module exports the following:

- `add`
- `addAll`
- `is`
- `remove`
- `removeAll`
