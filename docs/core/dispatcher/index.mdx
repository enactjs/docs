# core/dispatcher

Provides methods to add and remove global event listeners.


## Exports

This module exports the following:

- `off`
- `on`
- `once`


## API Reference


## Functions

### on

<span className="badge badge--secondary">function</span> 

Adds a new global event listener. Duplicate event handlers will be discarded.


#### Parameters

<Tabs>
  <TabItem value="name" label="name">
    **Type:** `String`

    Event name
  </TabItem>
  <TabItem value="fn" label="fn">
    **Type:** `Function`

    Event handler
  </TabItem>
  <TabItem value="target" label="target">
    **Type:** `Node`

    Event listener target
  </TabItem>
</Tabs>


#### Returns

**Type:** `any`

### once

<span className="badge badge--secondary">function</span> 

Adds a new global event listener that removes itself after handling one event.


#### Parameters

<Tabs>
  <TabItem value="name" label="name">
    **Type:** `String`

    Event name
  </TabItem>
  <TabItem value="fn" label="fn">
    **Type:** `Function`

    Event handler
  </TabItem>
  <TabItem value="target" label="target">
    **Type:** `Node?` *(optional)*

    Event listener target
  </TabItem>
</Tabs>


#### Returns

**Type:** `Function`

The single-use handler. To remove the handler manually, call
the `off()` function with this as the 2nd parameter.
