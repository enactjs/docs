# webos/pmloglib

Provides a wrapper around PmLogLib logging API


## Exports

This module exports the following:

- `emergency`
- `alert`
- `critical`
- `error`
- `warning`
- `notice`
- `info`
- `debug`
- `perfLog`

    **Type:** `String`

    A string that identifies the type of perf message
