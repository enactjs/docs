# webos/application

Provides a collection of functions for fetching application metadata.


## Exports

This module exports the following:

- `fetchAppId,`
- `fetchAppInfo,`
- `fetchAppRootPath,`
- `platformBack`


## API Reference


## Functions

### fetchAppId

<span className="badge badge--secondary">function</span> 

Fetches the appID of the caller app.


#### Returns

**Type:** `String`

AppID of the app


---

### fetchAppInfo

<span className="badge badge--secondary">function</span> 

Fetches the *appinfo.json* data of the caller app.


#### Parameters

<Tabs>
  <TabItem value="callback" label="callback">
    **Type:** `webos/application~appInfoCallback`

    Called upon completion
  </TabItem>
  <TabItem value="path" label="path">
    **Type:** `String?` *(optional)*

    Optional relative filepath to a specific *appinfo.json* to read
  </TabItem>
</Tabs>


#### Returns

**Type:** `any`


---

### fetchAppRootPath

<span className="badge badge--secondary">function</span> 

Fetches the full root URI (path) of the caller app.


#### Returns

**Type:** `String`

App's URI (application install path)


---

### platformBack

<span className="badge badge--secondary">function</span> 

Emulate the remote *back* key.


#### Returns

**Type:** `any`


---
