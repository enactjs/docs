# webos/keyboard

Provides a function to check visibility of virtual keyboard.


## Exports

This module exports the following:

- `isShowing`


## API Reference


## Functions

### isShowing

<span className="badge badge--secondary">function</span> 

Checks if the virtual keyboard is visible (only works on SmartTV platform).


#### Returns

**Type:** `Boolean`

`true` if the virtual keyboard is displaying
