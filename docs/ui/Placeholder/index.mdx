# ui/Placeholder

Exports the [ui/Placeholder.PlaceholderControllerDecorator](#ui-placeholder.placeholdercontrollerdecorator) and
[ui/Placeholder.PlaceholderDecorator](#ui-placeholder.placeholderdecorator) higher-order components.

The default export is [PlaceholderDecorator](#ui-placeholder.placeholderdecorator).


## Exports

This module exports the following:

- `PlaceholderControllerDecorator`
- `PlaceholderDecorator`


## API Reference


### Classes

#### PlaceholderDecorator

<span className="badge badge--secondary">class</span> 

A higher-order component that enables a container to notify the wrapped component when scrolling.

Containers must provide `registerPlaceholder`, `unregisterPlaceholder`, and `invalidateBounds`
methods via React's context for `PlaceholderDecorator` instances.

No additional properties are passed to the wrapped component.


---


#### Static Members

##### defaultConfig

<span className="badge badge--secondary">constant</span> 

Default config for PlaceholderDecorator.


---

#### PlaceholderControllerDecorator

<span className="badge badge--secondary">class</span> 

A higher-order component (HOC) that renders placeholder components.

Components are rendered based on their position relative to the `'scrollTop'` from the
`'onScroll'`'s parameter. They are not unmounted once rendered.


---


#### Static Members

##### defaultConfig

<span className="badge badge--secondary">constant</span> 

Default config for `PlaceholderControllerDecorator`.
