# ui/ImageItem

Unstyled image item components and behaviors to be customized by a theme or application.


## Exports

This module exports the following:

- `ImageItem`
- `ImageItemBase`
- `ImageItemDecorator`


## API Reference


### Classes

#### ImageItemBase

<span className="badge badge--secondary">class</span> 

A basic image item without any behavior.


---


#### Instance Members

##### children

The caption displayed with the image.


---

##### componentRef

Called with a reference to the root component.

When using [ui/ImageItem.ImageItem](#ui-imageitem.imageitem), the `ref` prop is forwarded to this component
as `componentRef`.


---

##### css

Customizes the component by mapping the supplied collection of CSS class names to the
corresponding internal elements and states of this component.

The following classes are supported:


- `imageItem` - The root component class
- `caption` - The caption component class
- `horizontal` - Applied when `orientation="horizontal"
- `image` - The image component class
- `selected` - Applied when `selected` prop is `true`
- `vertical` - Applied when `orientation="vertical"


---

##### imageComponent

The component used to render the image component.


---

##### orientation

The layout orientation of the component.


---

##### placeholder

A placeholder image to be displayed before the image is loaded.


---

##### selected

Applies a selected visual effect to the image.


---

##### slotBefore

Nodes to be inserted before `image`.

For LTR locales, the nodes are inserted to the left of the image. For RTL
locales, the nodes are inserted to the right. If nothing is specified, nothing, not even
an empty container, is rendered in this place.


---

##### src

String value or Object of values used to determine which image will appear on a specific
screenSize.


---

#### ImageItem

<span className="badge badge--secondary">class</span> 

A minimally styled ImageItem ready for customization by a theme.
